## 📌 About This Repository

Welcome to **Sample Datasets**!

This repository is a continuously growing collection of datasets designed for data enthusiasts, students, developers, and aspiring data engineers.

Here, you will find datasets in different formats that can be used for hands-on practice, learning, experimentation, and building real-world projects.

Whether you are working with Python, SQL, Pandas, PySpark, Machine Learning, or Data Engineering, this repository aims to provide useful datasets for your learning journey.

## 🎯 What You Will Find

- 📄 **CSV Files** – Comma-separated datasets for data analysis.
- 📊 **Excel Files** – Structured datasets in XLS and XLSX formats.
- 🔗 **JSON Files** – Data in JSON format for handling semi-structured data.
- 🗄️ **SQL Data** – Sample data for database operations and SQL practice.
- ⚡ **Big Data Datasets** – Datasets for Apache Spark and PySpark practice.
- 🤖 **Machine Learning Data** – Sample datasets for experimentation and model building.

## 📥 How to Use This Repository

**Option 1: Clone the Repository**

```bash
git clone https://github.com/AtharvaFDE/Sample-Datasets.git
```

**Option 2: Download Individual Datasets**

1. Navigate to the required dataset folder.
2. Open the dataset you want to use.
3. Click the Download Raw File option or download the repository.
4. Use the dataset in your preferred tool or programming language.
